app-20-llmchat

React component library for LLM chat interfaces.

Install

npm install app-20-llmchat

Example

A minimal chat with 3 components:

import { useState } from 'react'
import { LLMChat } from 'app-20-llmchat'

export default function App() {
  const [messages, setMessages] = useState([])
  const [draft, setDraft] = useState('')
  const [status, setStatus] = useState('idle')

  const handleSend = () => {
    if (!draft.trim()) return
    setMessages(prev => [...prev, { id: Date.now(), role: 'user', content: draft }])
    setDraft('')
  }

  return (
    <LLMChat.Root
      messages={messages}
      draft={draft}
      status={status}
      onChangeDraft={setDraft}
      onSubmit={handleSend}
      onStop={() => {}}
      onLoadEarlier={() => {}}
    >
      <LLMChat.Conversation />
      <LLMChat.PromptInput />
    </LLMChat.Root>
  )
}

Components

  • LLMChat.Root - Main container
  • LLMChat.Conversation - Message list
  • LLMChat.PromptInput - Text input
  • LLMChat.Bubble - Message bubble
  • LLMChat.Status - Status badge
  • LLMChat.SendButton - Send button
  • LLMChat.StopButton - Stop button
  • LLMChat.ScrollToLatest - Scroll control
  • LLMChat.LoadEarlier - Load more
  • LLMChat.UnreadBadge - Unread count
  • LLMChat.EmptyState - Empty state
  • LLMChat.LoadingState - Loading
  • LLMChat.TypingState - Typing indicator
  • LLMChat.ErrorState - Error state
